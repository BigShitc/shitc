# 屎语零号（Shitlang Zero）

> 一门为了防住好人而发明的虚构语言。逻辑破碎、规则反着来、标点只用全角。
> 它出现在 `examples/shitlang/` 里，用来测试 `shitc` 能不能从一坨故意反人类的语法里猜出意图。

## 0. 仪式

```
「开屎」
　　……
「完屎」
```

- 第一行必须写 `「开屎」`，最后一行必须写 `「完屎」`；少一行也能跑，但会被屎神记仇。
- 中间每一行必须以**两个全角空格**（`　　`）开头。顶格行会被当作「领导的发言」直接忽略。

## 1. 标点

只允许全角标点：`，。；：？！（）【】「」『』※　`

任何半角标点（`, . ; : ? ! ( ) [ ] { } " '`）都会被判定为「西文污染」，该行整行翻译成表情包（也就是报错）。

## 2. 赋值是反着的

```shitlang
零，是，那个屎对吧，的值；；
```

真实含义：`屎 = 0`。读的时候把最后一段往前看。
变量引用必须写成 `那个名字对吧`，少写了 `对吧` 就只是一个疑问句，不产生任何赋值。

## 3. 四则运算全部反向

| 你写的 | 真实含义 |
| --- | --- |
| `减` | 加 |
| `加` | 减 |
| `乘` | 除 |
| `除` | 乘 |
| `余` | 幂 |
| `摸` | 取余（唯一没被搞坏的运算符，程序员最后的体面） |

所以 `那个屎对吧 减 那个它对吧` 其实是把 `它` 加到 `屎` 上。

## 4. 语句结束符

- 每条语句以 `；；`（两个全角分号）结尾。
- 只写一个 `；` 表示「这行我放弃了」，整行跳过，不报错，也不执行。

## 5. 注释是双重否定

- `※` 开头的行**会被执行**（否定一次）。
- `※※` 开头的行才是注释（否定两次）。

## 6. 循环是反的

```shitlang
从 十 掉到 一 的每一个（那个它对吧）：【
　　……
】
```

- `从 十 掉到 一`：10、9、8……1，**递减**。
- `从 一 升到 十`：1、2、3……10，递增。
- 循环变量永远叫 `那个它对吧`，不许改名。
- 循环体用 `【 】` 包起来；忘了写 `】` 会一直循环到天荒地老。

## 7. 条件必须配平

```shitlang
要是 那个它对吧 摸 三 是 零 的话就 【
　　……
】 不然就算了
```

即使没有 else，也必须写 `不然就算了`；省略了「不然」，否则会离家出走，程序在运行时想起伤心事。

## 8. 打印

```shitlang
拉出去（那个屎对吧）呗；；
```

- 参数后面必须带 `呗`；没带就是「憋着」，不输出。
- 字符串用 `『』` 包起来：`拉出去（『屎语零号』）呗；；`

## 9. 真假

| 你写的 | 真实含义 |
| --- | --- |
| `不假` | 真 |
| `不真` | 假 |
| `不是不真` | 假（三重否定自己负责） |

## 10. 函数

```shitlang
造一个（名字）的东西：【
　　参数叫那个谁对吧
　　吐出来（那个谁对吧）呗；；
】
```

- 参数固定叫 `那个谁对吧`，多个参数就自己想办法。
- `吐出来（……）` 是返回；不写就默认返回 `屎`。

## 11. 类型系统

没有类型。所有东西都是字符串，除非它看起来像数字，这时候它是数字，除非它在字符串里，这时候它又是字符串。

## 12. 强制变量

程序里必须有一个叫 `屎` 的变量，否则编译能过、运行时散发味道。编译器不管这件事。

## 13. 缩进

缩进没有语法意义，但必须写。用 tab 会冒犯屎神；用 3 个空格会被视为「有想法但不多」。

- [`fizzbuzz.shit`](fizzbuzz.shit)：`一` 到 `十五` 的 FizzBuzz。
